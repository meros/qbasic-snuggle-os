# Snuggle OS API

Generated by `snuggle docs` from `os/kernel` (the `'@api` lines). Do not edit by hand.
How the pieces fit: docs/ARCHITECTURE.md.

## App module

An app is one file in `os/apps/` that starts with a manifest line:

```
'@app id=2 name=Clock start=ClockStart timer=ClockTimer uses=controls,timers
```

| Field | Meaning |
| --- | --- |
| `id` | app number, unique; the builder adds `CONST AppId<Name>` |
| `name` | label of the desktop icon |
| `boot` | start one instance when the desktop starts |
| `uses` | the parts of the kernel the app needs (below); what they require comes with them |
| `opaque` | the paint procedure paints all of the client area, so the kernel skips the white fill under it |
| `start`, `event`, `paint`, `key`, `timer` | the name of a callback procedure (below) |

## Callbacks

| Manifest field | Signature | When |
| --- | --- | --- |
| `start=` | `SUB Name ()` | Make an instance: its windows (AppWindow), controls and timers. Runs for a desktop click and for `boot`. |
| `event=` | `SUB Name (win, ctl)` | A retained control of the window was clicked, toggled or accepted. |
| `paint=` | `SUB Name (win)` | Declare immediate mode controls (UiButton, UiLabel). Runs in draw, find and click mode. |
| `key=` | `SUB Name (win, k$)` | A key while a window of the app is in front. An arrow key is CHR$(0) and a letter (H up, P down, K left, M right). |
| `timer=` | `SUB Name (win, tag)` | A timer set with TimerSet ran out. |

Instance state lives in the window's data block (`AppGet`, `AppSet`), so one
app can run in several windows. An app that asks for something the heap cannot
give gets 0 and `OomFlag`; the kernel then closes the half made instance and
shows a notice, so an app need not check each call.

## Windows

| Procedure | What |
| --- | --- |
| `AppWindow (app, title$, x, y, w, h, words)` | Make a window of the app with a data block of `words` words, cascaded 24 px for each open window. Returns the window number, 0 when the heap has no room. |
| `AppGet (win, i)` | Word `i` of the window's data block (0 when out of range). |
| `AppSet (win, i, v)` | Set word `i` of the window's data block (ignored when out of range). |
| `AppBlock (win)` | A one word block owned by the window that holds a string. Returns its handle, 0 when the heap is full. |
| `BlockText$ (h)` | The string of a block made with `AppBlock`. |
| `BlockSetText (h, t$)` | Set the string of a block made with `AppBlock`. |
| `WinInvalidate (who)` | Repaint the client area of a window after the app changed what it shows. |
| `WinDirty (who, x, y, w, h)` | Mark a rectangle of the client area as changed (cut to the client area); `WinFlush` repaints the marks. |
| `WinFlush` | Repaint the rectangles marked with `WinDirty`. |
| `WinClose (win)` | Close a window: its controls, blocks and timers go, and the area is repainted. |
| `WinPutTop (who)` | Bring a window to the front. |
| `WinRect (who, x1, y1, x2, y2)` | The screen rectangle of a window, both ends included. |
| `WinMoveTo (who, nx, ny)` | Move a window to x, y. Only what changed is repainted. |
| `WinSizeTo (who, nw, nh)` | Resize a window. Only what changed is repainted. |
| `WinSetState (who, st)` | Set the state of a window: 0 rolled up, 1 normal, 2 maximised. |
| `Notice (msg$)` | Show a line of text on the bar at the bottom of the screen for 4 seconds. |

## Heap

| Procedure | What |
| --- | --- |
| `MemAlloc (owner, kind, n)` | A zeroed block of `n` words of a kind (KData for app data) owned by a window. Returns its handle, 0 and OomFlag when full. |
| `MemFree (h)` | Free one block and close the gap. |
| `MemFreeAll (owner)` | Free every block a window owns. |
| `MemGet (h, i)` | Word `i` of a block (0 when out of range). |
| `MemSet (h, i, v)` | Set word `i` of a block (ignored when out of range). |

## Immediate mode

| Procedure | What |
| --- | --- |
| `UiButton (id, x, y, w, h, cap$)` | A push button (`id` 1 or more, x and y relative to the client area). Returns -1 when it was clicked (only in the click pass), so the app does its work in the IF. |
| `UiW` | Width of the client area, in a paint procedure. |
| `UiLayout` | -1 in the layout pass, the first call of the paint procedure when a window is drawn: place controls with `CtlPlace` and draw nothing. |
| `UiH` | Height of the client area, in a paint procedure. |
| `UiFill (x, y, w, h, c)` | A filled rectangle in colour `c`, relative to the client area and cut to it. |
| `UiLabel (x, y, w, h, t$)` | Text in black on the client area, `h` high. |

## Timers

| Procedure | What |
| --- | --- |
| `TimerSet (app, win, tag, secs!)` | Call the app's timer procedure once after `secs!` seconds with `tag`. Setting the same app, window and tag again starts over. |

## Controls

| Procedure | What |
| --- | --- |
| `CtlAdd (win, kind, x, y, w, h, cap$)` | Add a retained control (CtlLabel, CtlButton, CtlCheck, CtlRadio or CtlText) to a window. Returns its number, 0 when the heap is full. |
| `CtlPlace (id, x, y, w, h)` | Move and size a control. Call it in the paint procedure when `UiLayout` is -1 (the layout pass, before the controls are drawn). |
| `CtlSetFocus (id)` | Give the keys to a text box, 0 for none. |
| `CtlSelect (id)` | Select a radio button and clear the others of its group. |
| `CtlSetText (id, t$)` | Set the text of a control and repaint it. |
| `CtlGetText$ (id)` | The text of a control (the text box content, a caption). |
| `CtlSetChecked (id, v)` | Check or uncheck a check box or radio button. |
| `CtlGetChecked (id)` | -1 when a check box or radio button is checked. |
